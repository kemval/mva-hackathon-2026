# Tool/Resource Overviews: HPO, Open Targets, DGIdb, Exomiser

Captured: 2026-08-31

## Human Phenotype Ontology (HPO)
Source: https://hpo.jax.org/

"The Human Phenotype Ontology (HPO) provides a standardized vocabulary of phenotypic abnormalities encountered in human disease. Each term in the HPO describes a phenotypic abnormality, such as Atrial septal defect. The HPO is currently being developed using the medical literature, Orphanet, DECIPHER, and OMIM. HPO currently contains over 18,000 terms and over 156,000 annotations to hereditary diseases."

The HPO project has developed software for phenotype-driven differential diagnostics, genomic diagnostics, and translational research. It's a central component of a Global Alliance for Genomics and Health (GA4GH) driver project. Related tools listed on the site: **Exomiser** (evaluate variants by predicted pathogenicity), **Phenomizer** (rank disease differential diagnosis by clinical features — noted offline at capture time), **Genomiser** (analyze genome sequence data for non-coding variants), Profile Search (discover diseases with a phenotype profile). **Phenopackets** is the GA4GH standard for phenotypic data exchange — worth checking if the hackathon's clinical data is provided in this format.

**Use in this project**: the case's provided "standardized HPO terms" (per Official Rules) are the direct input format for Exomiser/Genomiser. Learn the HPO browsable hierarchy (hpo.jax.org's search) to map free-text symptom descriptions to exact HPO IDs if needed.

## Open Targets Platform
Source: https://platform.opentargets.org/

"The Open Targets Platform is a comprehensive tool that supports systematic identification and prioritisation of potential therapeutic drug targets. By integrating publicly available datasets including data generated by the Open Targets consortium, the Platform builds and scores target-disease associations to assist in drug target identification and prioritisation. It also integrates relevant annotation information about targets, diseases or phenotypes, variants, GWAS studies and drugs, as well as their most relevant relationships."

Freely available, actively maintained with quarterly data updates (last update at capture: June 2026). Access via web UI, GraphQL API, or full data downloads. Open-source pipeline/infrastructure; CC0 1.0 licensed. Partners include EMBL-EBI, Genentech, GSK, MSD, Pfizer, Sanofi, Wellcome Sanger Institute.

**Use in this project**: primary tool for Weeks 5-6 systematic drug-target search — query BUB1B (or the confirmed causal gene) and pathway-adjacent genes directly in the web UI, and consider the GraphQL API for a reproducible, scriptable query (feeds the "Scalability" deliverable — a reusable query script).

## DGIdb (Drug Gene Interaction Database)
Source: https://www.dgidb.org/

"An open-source search engine for drug-gene interactions and the druggable genome." Version at capture: v5.0.12. Provides gene-level interaction search, bulk search, API, and downloads.

Explicit disclaimer worth noting for the report's limitations section: "This resource is intended for purely research purposes... A finding of a drug-gene interaction or potentially druggable category does not necessarily indicate effectiveness (or lack thereof) of any drug or treatment regimen... not presented in ranked order of potential or predicted efficacy."

**Use in this project**: second-pass cross-check against Open Targets results — different underlying source databases, useful for triangulating candidate drugs and catching anything Open Targets misses. Cite the disclaimer language directly when framing Track 2 candidates as hypotheses, not proven treatments (matches the track's own required framing).

## Exomiser
Source: https://github.com/exomiser/Exomiser (README)

Java application for identifying disease-causing genetic variants from exome/genome VCF files via annotation, filtering, and phenotype-driven prioritization.

**Scoring inputs**:
- Pathogenicity predictions from dbNSFP (PolyPhen, SIFT, MutationTaster)
- Population frequencies (1000 Genomes, ExAC, gnomAD, etc.)
- Cross-species phenotype matching via PhenoDigm/OWLSim algorithms
- Inheritance pattern analysis and quality filters

**Workflow**: provide VCF + HPO-coded phenotype terms → configure analysis parameters (genome build, inheritance mode, frequency thresholds) → select annotation/filter steps → run → get ranked candidate variants. Runs as CLI or as a Spring-based Java library.

**Use in this project**: this is the single most directly-matched tool to the hackathon's own task framing ("using their clinical symptoms and genomic data"). Note several Track 1 leaderboard filenames already reference "exomiser" (e.g. `paraxaQQ_exomiser15-cis-aware.csv`) — confirms this is a standard, expected tool for this task, not a novel choice; the differentiator will be in how carefully the HPO term set and inheritance model are configured, not in tool choice alone.
